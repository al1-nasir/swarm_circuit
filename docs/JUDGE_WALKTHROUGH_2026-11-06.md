## What to demonstrate

**SwarmCircuit helps a developer inspect and pause an affected branch of an
existing Python agent workflow, then verify the runtime's response.** It uses
cooperative SDK checkpoints; it does not stop arbitrary code or create an agent
team for you.

Use the sales-brief walkthrough to make the control path understandable:

1. Open Overview and choose **Explore the guided demo → Start walkthrough**.
   Explain the job: public notes are available now, while a sample sales dataset
   needs one permission. Four tasks depend on that decision.
2. Read the public findings. They finish independently of permission and control
   requests. The display shows 2/6 tasks complete, not 100% of the workflow.
3. Open the workflow map and Approvals. Review the affected tasks, enter a reason,
   and inspect the preview: four tasks in scope, two outside. Request the pause
   and wait for matching worker confirmations. A queued request is not success.
4. Return to the walkthrough and grant sample access. The protected-effect count
   must remain zero while the operator pauses remain in place.
5. Choose **Review pauses to continue**. Resume the dataset task first, then the
   newly eligible analysis and validation tasks, then the final brief. Every
   resume has its own review and worker confirmation.
6. Return to the walkthrough and read/download the finished brief. Confirm 6/6
   tasks and four protected steps. Explain what the result actually says and its
   limitations. A second walkthrough can demonstrate denial retaining only the
   public output.

The sample is deterministic and makes no model calls. Do not call this a live
LLM-team benchmark, a measured cost saving, or evidence that a pause outperforms
the SDK's existing permission guards. The value shown here is understandable,
reviewed control and inspectable recovery.
